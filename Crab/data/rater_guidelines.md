# Crab 信心度評分指引（Rater Guidelines）

**版本：** v1.0
**目的：** 統一 10 位 rater（5 男 5 女）對「信心度」（Confidence）的判斷標準
**評分對象：** 合成中文語音（既有 560 筆 + 朋友新合成）
**評分量表：** Likert 5 分（1 = 非常沒自信 ~ 5 = 非常有自信）

---

## 1. 為什麼要做這個評分

我們訓練的模型要在面試錄音中判斷說話者「有沒有自信」（Unconfident vs Confident vs 中性）。

**沒有現成中文標籤可用**：

- 公開資料集（CH-SIMS、ESD、CASIA 等）標的是 happy/sad/angry，**都沒有 "Unconfident"**
- 合成資料雖然有 emotion 標籤（depressed / fear / sad），但 **depressed ≠ Unconfident**
  - 沮喪是低沉、悲傷
  - 沒自信是「不確定、遲疑、需要外部認可」
  - 兩者可能聽起來像，但訓練模型用 depressed 標 Unconfident 會教歪

**所以我們要 10 位 rater 親耳聽過合成語音，獨立評分**，作為訓練模型的 supervised signal。

---

## 2. 「信心度」的具體判斷指標

評分時請優先看以下**聲學特徵**和**語言特徵**：

### A. 聲學特徵（怎麼說）

| 特徵 | 高自信（5 分）→ 低自信（1 分） |
|------|------------------------------|
| **語速** | 流暢穩定 → 明顯減慢、不規則 |
| **停頓** | 自然斷句 → 句中卡頓、突然停頓 |
| **句末語調** | 平穩或下沉（陳述句的自然句末） | 上揚（變成像問句，「嗎？」感） |
| **音量** | 穩定、有底氣 → 越說越小、尾音弱 |
| **音調起伏** | 自然有變化 → 平板無起伏，或抖動 |
| **填充語** | 無 / 少 → 多（嗯、那個、就是、好像、可能） |

### B. 語言特徵（說了什麼）

| 特徵 | 高自信 | 低自信 |
|------|--------|--------|
| 句中遲疑詞 | 少 | 「嗯…」「呃…」「那個…」「就是…」 |
| 用語確定性 | 「我覺得」「我認為」「我會」 | 「我不太確定…」「應該」「好像」「可能」「也許」「不是很」 |
| 答覆完整度 | 完整句子，有結論 | 半句、改口、補充太多細節又收不回來 |

### C. 整體印象（最重要）

> **想像這個人在面試你的公司，你會錄用嗎？**
>
> - 5 分：聲音穩定、答覆乾脆、有條理。錄用機率高。
> - 4 分：大致流暢，偶有遲疑但能說完整。可接受。
> - 3 分：中性，沒特別有自信也沒特別沒自信。需更多資訊判斷。
> - 2 分：明顯遲疑、結巴、需要努力理解他想表達什麼。猶豫。
> - 1 分：完全沒自信、句子破碎、含糊不清。不會錄用。

## 3. 評分流程

### Step 1：閱讀此 guideline（5 分鐘）

確認你理解上面的判斷指標。

### Step 2：聽 5 個 calibration clip（10 分鐘）

我們會給你聽 5 個有「標準答案」的 clip，你先評分，再對照標準答案。目的是**校準你的尺度**。

- 2 個極自信（預期 5 分）
- 2 個極不自信（預期 1 分）
- 1 個中性（預期 3 分）

如果你的評分跟標準答案差 ≥ 2 分（例如標準是 5，你給 3），請重新讀 guideline 再聽一次。

### Step 3：正式評 560 筆 clip（~ 30–40 分鐘）

- clip 順序**已隨機打亂**（避免依序評產生 anchoring）
- 評完每個 clip 直接給 1–5 分，**不要回頭修改**
- 中途有 5 個 attention check clip（同一 clip 重複出現），測試你前後評分一致性
- **不會告訴你 clip 的合成 emotion 標籤**（盲標）
- 標準答案沒有對錯，**你的直覺判斷就是訓練 signal**

### Step 4：（可選）填寫備註

某些 clip 你覺得「介於兩個分數中間」或「跟其他不同類」，可以在備註欄寫 1 句說明。

---

## 4. 注意事項

### 4.1 不要被 emotion 標籤影響

- 合成資料是有 `depressed / sad / fear / angry / happy` 等情緒標籤
- **這跟信心度無關**
- 一個 `happy` 的人可能很有自信也可能沒自信（裝開心）
- 一個 `sad` 的人可能很有自信地表達悲傷（悲傷但篤定）
- 請**只看信心度**，不要被 emotion 標籤帶歪

### 4.2 內容主題不影響評分

合成的句子主題各異（天氣、夢想、挑戰…），主題本身不是信心度的依據。**怎麼說**遠比**說什麼**重要。

### 4.3 跨語言鑒別

- 你母語是中文 → 直接用中文聽感判斷
- 若 clip 中夾雜英文（合成資料皆中文，理論上不會），請仍依中文聲學特徵判斷

### 4.4 評分耗時

- 每 clip 約 5–10 秒
- 整體 560 clip × 7 秒 ≈ 65 分鐘聽 + 評分時間
- 建議分 2 個 session 做（中間休息），避免疲勞影響評分

## 5. Calibration clip 答案說明（評分時看不到，校準後解釋）

| Clip ID | 預期分數 | 為什麼 |
|---------|---------|--------|
| cal_01 | 5 | 流暢、語調穩、無填充語 |
| cal_02 | 5 | 有條理、用字確定、結尾平穩 |
| cal_03 | 1 | 多填充語、句末上揚、語速慢 |
| cal_04 | 1 | 結巴、停頓多、音量小 |
| cal_05 | 3 | 中性、無明顯自信也無明顯沒自信 |

實際 clip 由 [`calibration_set.csv`](calibration_set.csv) 指定。

## 6. 給 rater 招集者的紀錄要求

每位 rater 評完，紀錄系統需保存：

| 欄位 | 說明 |
|------|------|
| rater_id | 1–10 |
| rater_gender | M / F |
| rater_age | 整數 |
| rater_mandarin_native | yes / no |
| rater_region | 台 / 中 / 港 / 其他 |
| clip_id | 對應到 wav 路徑 |
| score | 1–5 |
| timestamp | 評分時間 |
| note | 可選備註 |
| is_attention_check | bool（這條是重複 attention check） |

招集者匯總後產出 `Crab/data/rater_scores.csv`，後續會自動計算：

- **Inter-rater agreement κ**（Krippendorff's alpha,需 ≥ 0.4 才採用此 clip）
- **Intra-rater consistency**（同 rater 對 attention check clip 的兩次評分差距）
- **Mean / Std per clip**（給 U2 soft label 用）
- **Regional / Gender 偏差檢查**（看評分是否依 rater 屬性系統偏移）
