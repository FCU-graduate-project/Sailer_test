## 1. 與原規格的差異

| 原規格／可能誤讀 | 準備建議 | 理由 |
|---|---|---|
| ≤11 秒共同子集再加 2 秒底噪 | a～g 共用 ≤10 秒的 626 筆 | 11+2=13 秒，超過 loader 上限；不允許加完被截掉 |
| A 的 9 個 run 是 9 次相同條件重複 | 按 3 劑量 × 3 seeds 呈現；A/B 主要比較固定同劑量 seed42 | 9 個 run 的資料劑量不同，B 的 3 個也不是 3 seeds |
| A 比 B 更敏感即可證明學到零值捷徑 | 檢驗「與尾端零值敏感度假說相容」 | A/B 不只時長不同，也有內容裁切、訓練標準化統計與標籤有效性差異 |
| N3 是完全同訓練政策的 0% 對照 | 保留為歷史參考，另註 patience5 vs full10 | 原 N3 並非本輪重新訓練的匹配對照 |
| 最安靜片段就是無語音底噪 | 列為候選，須確認沒有語音、他人聲、笑聲或哭聲等 | 低 RMS 不能證明沒有語音／情緒內容 |

| 三類先驗差是整句英文反應的上限 | 改為待檢驗的參考方向／量級 | 模型反應不受這個資料比例差的硬上界限制 |
| 字元對齊可分辨音譯／意譯 | 對齊只定位候選；需要雙語判讀規則與人工 gold | 字元重疊不能辨識翻譯語意 |

## 2. 前測一：建議凍結內容

### 範圍與執行階段

```text
已完成：Train-only 尾端統計 + Test 資格 + 模型配置 + 七類先驗
    ↓
待決定：共同子集／noise 定義／CI 與等效判讀
    ↓
待完成：noise 來源定位與驗收 + GPU runner／單元測試
    ↓
重新查 queue 授權與資源 → 提交普通推論任務（不得自行設 urgent）
    ↓
少量 smoke + 原句 baseline 核對 → 全量推論 → 配對彙總與報告
```

GPU runner 還沒實作／驗收，這份文件不是可直接提交的 queue job。不得引用舊 9/27 測試授權作為本新任務的放行。

### 模型與樣本

- 13 個模型：新 A full10 的 9 個、B seed42 的 3 個、原 N3；不使用歷史早停 A 的權重替代新 A。
- 主要 A/B 對照：A25s42 vs B25s42、A50s42 vs B50s42、A75s42 vs B75s42。
- A seeds43/44 用來呈現各劑量的 seed 變動；不偽造 B 多 seed 對照。
- 預設建議共同子集 626 筆，保留原始真人文字、標籤及排序。不得依 baseline 正確與否、p(U) 大小或處理後的反應再選句。
- 以本次 Train-only 分位數決定追加長度；不得看模型反應後調整長度或噪音振幅。

### 七種處理

| 代號 | 內容 | 16 kHz 追加樣本數 | 目前狀態 |
|---|---|---:|---|
| a | 原句 | 0 | 原始來源已盤點 |
| b | 全零，中位數 | 259 | 長度已算；未生成／推論 |
| c | 全零，P90 | 1319 | 同上 |
| d | 真實底噪，中位數 | 259 | 待來源驗收 |
| e | 真實底噪，P90 | 1319 | 待來源驗收 |
| f | 全零，1 秒 | 16000 | 敏感度劑量，非典型 TTS 尾段 |
| g | 真實底噪，2 秒 | 32000 | 假設的部署模擬，不視為已核對的線上條件 |

13 × 626 × 7 = **56966 次單句條件推論**。未量測 pilot throughput，不能直接用舊一般 Test 耗時承諾完成時間。可以先安排 smoke；是否先跑同 seed 的七模型核心比較，待使用者確認，不自行省略原要求的 13 模型。

### 必須維持的波形與模型條件

1. 先沿用實際 evaluator 的讀音／mono／16 kHz 重取樣路徑，再追加原始振幅域尾段，最後使用**該 checkpoint 保存的 Train mean/std**標準化。不能在已標準化張量尾端填 0 來代表 PCM 數位靜音，也不能重算各測試條件的 mean/std。
2. 所有音訊長度在追加後驗證 ≤192000 samples，超長直接失敗，不能依 loader 靜默截前 12 秒。
3. 同一句的 d/e/g 使用同一個已驗收背景片段的固定起點，截取不同長度；跨模型完全重用。自然錄音振幅不額外 RMS／LUFS 匹配；如另設增益，須先固定並另列條件。記錄原取樣率、channel、切點、RMS、peak、原檔和處理後 hash。
4. 不加新的 fade、不用人工白噪音冒充現場底噪。純零／低 RMS／含語音的噪音候選需另標，不能靜默通過。
5. session WAV 檔名只提供候選來源，尚須確認其錄音 channel 與句級音訊對應，不能僅憑檔名斷言同一聲道／噪音條件。
6. transcript 在 a～g 固定；不重新跑 ASR，不改字數，不增加 silence token。模型 `eval()`、無 gradient，一次只載入一個 checkpoint。
7. 注意 attention mask 必須包含追加尾段。尾段不是 padding；批次 padding 不得被當作刺激。
8. 基準 a 的同句重測應可重現。正式輸出保存未四捨五入的 logits、p(E/U/N)、模型／句／條件 ID、音檔與文字 hash、實际樣本數和耗時。原始逐字稿不放公開 repo。

### 統計與假說，待確認後凍結

前測一的指標是 U 對其餘兩類的 log-odds，與前測二的 U/N 不同：

\[
\ell_U=z_U-\log(\exp(z_E)+\exp(z_N))=\log\frac{p_U}{1-p_U}.
\]

優先由 logits 用穩定 logsumexp 計算；若只能取得 probabilities，必須先固定 clip epsilon 並報告觸發次數。不要以 API 顯示用的四捨五入機率計算。

- 每句先作差：b−d、c−e 為同長零值相對真實底噪；f−a、g−a 為敏感度與部署模擬。
- 對每個模型分開報平均、95% **配對句子 bootstrap CI**。建議 10000 draws、analysis seed=20260930，每次跨條件／模型重用相同句 ID 重抽；CPU 分批或逐次重抽，不一次配置巨大矩陣。
- A/B 再算同句、同劑量、seed42 的差中差，CI 也須配對，不用兩個独立 CI 的重疊與否判斷差異。
- 同樣本的多個 seeds 不新增真人样本量；A 各劑量報三 seed 結果與平均，不能把 9 個不同劑量 run 視為 iid 重複。B 各劑量只有一個 seed。
- 語者／session 內句子相關：句子 bootstrap CI 只當固定這些模型及本批句子的探索性區間；另做按 team 的 cluster 敏感度分析。Test 只有四個 teams，需明說 cluster 推論很不穩，不能聲稱廣泛人口泛化。
- 主要對比有多重性：建議 P90 的 c−e 作主要零值對比，中位數為次要；若仍同時檢定多劑量／多對比，須先決定校正方法。這是建議，尚未替使用者定案。
- 保留原假說：A 的零值相對底噪差較大；B/N3 小；A 劑量越高差越大。逐項如實報告，不要求單調結果才保留資料。沒有 δ 前，不作「已等效於 0」判定。

這只能探測模型敏感度；即使 A>B，也不能單憑它排除韻律、長度、內容及 normalization 的影響而斷言 TTS 訓練產生了因果捷徑。反之未見效應，也不證明任何時長的靜音都無影響。

## 3. 前測二：錄音前先修訂

- 20 詞 × 5 版本保留為候選；此輪未錄音、未產生評分。
- 固定隨機順序與錄音設備，避免把所有英文集中後錄；保留音訊、人工文字、詞 ID、版本、順序與重錄原因。
- 原 V1 是三類 checkpoint。若計畫改為七類，需要另一個已訓練且驗證的七類模型；不能只更改 output names，不能把本輪計數當成七類模型已完成。
- +0.753／+0.725 是先驗向量，不是模型輸出的上限。錄音同時改動音訊與文字，因此不能用一次多模態位移就唯一認定語言先驗機制。
- 事先固定 10 詞估 α／10 詞驗證的分組，相關近義詞避免任意跨集合造成樂觀估計；所有版本按詞一起 bootstrap。
- 位移接近零時方向角不穩，需報向量分量與幅度；角度 CI 要用圓形統計處理，不直接把跨 −180/180 的數字作普通百分位。
- 原規格的機制判讀改稱「較相容的解釋」，不能把單一說話者的結果寫成因果機制已證實。

## 4. 前測三：先放待辦，不下載／不占 GPU

原規格指定 `ky552/ML2021_ASR_ST` 與 Whisper-large-v2；本輪未查核其資料卡、授權、split、逐字稿是否人工、講者組成或本機模型 cache，不把規格中的描述當成已驗證事實。

啟動前需先核對上述資訊，再固定 ASR checkpoint revision、transcribe（非 translate）、language=zh vs auto、temperature、beam、prompt、VAD 與重取樣。英文詞 tokenization／專名／縮寫／一詞多譯的分母與規則也須先定義。

字元對齊只能產生候選；音譯／意譯需要人工或經驗證的雙語標註流程。100 處抽查須記錄抽樣設計、gold、各類 precision/recall 或一致率，不能只報一個「自動分類正確率」後忽略類別不均衡。無法判斷的例子應保留 ambiguous/unresolved，不強迫塞入五類。
