# 入學前前測規格（給 3090 主機執行）

2026-09-30。兩位教授角色的第 4 輪都說：研究計畫 5.0 的能力證明要穩在 9，送件前最好至少跑完一個前測，寫出數字、信賴區間與事先寫好的判讀。前測一最乾淨、最快，也最能證明「會懷疑自己的資料」，建議先做。三個前測都不訓練、不改任何既有檔案（前測二要你自己錄音，其餘只做推論）；結果另存新資料夾。編號和研究計畫 5.0 第 2 版一致：前測一是尾端零值檢驗，前測二是自錄的最小對比，前測三是辨識器把英文寫成中文的比例。

## 可以直接貼給 3090 agent 的指示

```
請在這台機器上執行下面的「前測一」（必要）與「前測三」（有時間再做），只做推論，不訓練、不修改任何既有檔案；所有輸出（腳本、數字、表格）另存到新資料夾 pilot_20260930/。每個數字都要附來源（腳本路徑、run ID、資料清單），查不到或做不到就寫明，不要推測。

前測一：數位靜音的尾端檢驗
目的：專題的合成語音擴增只加在「缺乏自信」(U) 類。A 組合成句常在結尾留有連續零值樣本（A75 的 471 句中 372 句結尾至少有一個零值樣本，多數可能只有幾個樣本，最長約 257 ms；長度分布還沒算過），B 組（Match-min1 切段）幾乎沒有。檢查加了 A 組合成語音的模型，會不會把「句尾的數位零值」當成缺乏自信的線索。
1. 先算 A75 那 471 個合成 WAV 的「結尾連續零值樣本」長度分布（毫秒）：中位數、九十百分位、最大值，以及長度大於 10 ms、50 ms、100 ms 的句數。
2. 測試句：NNIME 測試切分（team 4、20、21、22，共 638 句）的真人語音。先確認 CRAB 載入器對長音訊的裁切方式（是否只取前 12 秒）；若只取前 12 秒，只用長度 11.0 秒以內的句子，以免接在尾端的片段被切掉。記錄最後用了幾句。
3. 每一句做這幾種處理（在 16 kHz 波形上，接在句尾）：
   a. 原句
   b. 接全零段，長度 = 步驟 1 的中位數
   c. 接全零段，長度 = 步驟 1 的九十百分位
   d. 接底噪，長度同 b（底噪取自同一場 NNIME 錄音的非語音段；取不到就取同一 session 最安靜的一段，寫明做法）
   e. 接底噪，長度同 c
   f. 敏感度劑量：接 1 秒全零
   g. 部署條件：接約 2 秒的底噪（模擬面試系統前端安靜 2 秒才停止錄音時，錄音尾端留下的低音量底噪）
4. 模型：
   - A 組：對比損失權重相同、只差劑量與種子的 A 系列 run（A25、A50、A75 各三個種子，共 9 個；先核對它們的對比損失權重是否相同，不同就寫明並只用相同的那些）
   - B 組：B25、B50、B75（3 個 run）
   - N3（未加合成語音）
5. 每個模型、每種處理，記錄每句的三類機率，算「缺乏自信」的對數勝算 log(p/(1-p))。主要的量是每句的「接全零 − 接等長底噪」之差（b−d、c−e），以及敏感度劑量 f−a、部署條件 g−a。
6. 彙總：每個模型取句子平均；A 組以 9 個 run 當重複、B 組 3 個 run、N3 1 個 run；句子層級用拔靴法給 95% 信賴區間。
7. 事先寫下的預測（照實回報是否成立）：A 組的「接全零 − 接底噪」大於 B 組與 N3；B 組與 N3 接近 0；劑量越高（A75 > A50 > A25）差距越大。另回報部署條件 g−a 在三組的大小。
8. 輸出一張表：模型組 × 處理的平均變化與信賴區間，加一段文字說明哪些預測成立、哪些不成立。兩種結果都是有用的結論。

前測三：語音辨識把句中英文寫成中文的頻率（有時間再做）
1. 資料：NTUML2021（Hugging Face 的 ky552/ML2021_ASR_ST）的測試切分，只取人工逐字稿含英文詞的句子。
2. 用 Whisper-large-v2 各跑兩種設定：強制中文、自動偵測語言；寫明其他解碼設定。
3. 對每個人工逐字稿裡的英文詞，分類它在辨識結果中的去向：保留英文、音譯成漢字、意譯成中文、刪除、辨識成別的英文詞。先用字元層級的對齊自動分類，再人工抽查約 100 處，報告自動分類的正確率。
4. 輸出：兩種設定下五類的比例與句數；寫明 NTUML2021 以單一講者為主、課堂語域，只當基準率。
```

## 前測二：部署案例的模型端機制檢查（要你自己錄音）

這一項用你自己的聲音，不涉及其他受試者，錄音約 30 到 40 分鐘。目的是看 V1 在「只把一個詞換成英文」時，輸出會不會沿著兩個語料的類別先驗差移動（從 V1 訓練清單算出的預測：相對「平穩」，情緒高昂與缺乏自信的對數比各上升 +0.75 與 +0.72，這是整句英文時的上限；在兩個對數比的平面上，方向角約 43.9°）。

錄音內容（詞表是草稿，你可以換成自己平常會說的詞；句框都用同一句、目標詞放在句末、中性語氣）：

句框：「下一個要討論的是＿＿。」整句英文版：「The next thing to discuss is the ＿＿.」

| # | 英文 | 華語 | 華語同義 |
|---|---|---|---|
| 1 | deadline | 期限 | 截止日 |
| 2 | project | 專案 | 計畫 |
| 3 | report | 報告 | 書面報告 |
| 4 | email | 郵件 | 信件 |
| 5 | bug | 錯誤 | 漏洞 |
| 6 | server | 伺服器 | 主機 |
| 7 | schedule | 時程 | 行程 |
| 8 | budget | 預算 | 經費 |
| 9 | feedback | 回饋 | 意見 |
| 10 | demo | 展示 | 示範 |
| 11 | paper | 論文 | 文章 |
| 12 | code | 程式碼 | 程式 |
| 13 | data | 資料 | 數據 |
| 14 | slides | 投影片 | 簡報 |
| 15 | task | 任務 | 工作 |
| 16 | issue | 問題 | 議題 |
| 17 | update | 更新 | 版本 |
| 18 | spec | 規格 | 需求 |
| 19 | review | 審查 | 檢視 |
| 20 | plan | 規劃 | 計畫書 |

每個詞錄五個版本：夾英文、華語、華語同義、華語再唸一次（重錄雜訊底線）、整句英文；共 100 句。順序隨機、同一次錄完，用平常說話的語氣。

分析（可交給 3090 agent）：
1. 用 V1 的部署設定（音訊加人工逐字稿）跑每一句，記三類機率，算 log(p情緒高昂/p平穩) 與 log(p缺乏自信/p平穩)。
2. 每個詞，算夾英文版、同義版、重錄版、整句英文版相對華語版的位移；以詞為單位拔靴，報兩個對數比的平均位移、方向角與 95% 信賴區間。
3. 一半的詞估一個 α（位移 ≈ α × 先驗差），另一半的詞與整句英文驗證同一個 α 是否也說得通。
4. 另報熵的變化，以及位移是否隨句子改變（各詞位移的變異是否大於重錄底線）。
5. 事先寫好的判讀：

| 觀察 | 解讀 |
|---|---|
| 夾英文句沿先驗差的方向移動，位移不隨句子改變，同義版不超過重錄底線 | 支持依語言切換先驗 |
| 夾英文句移得比整句英文多，或位移隨句子改變、同義版也動 | 支持「陌生輸入、退回中點」（至少不是只有先驗切換） |
| 只有情緒高昂（或只有缺乏自信）上升 | 像加重（或停頓）的聲音路徑，不是先驗 |
| 位移不超過重錄底線 | 這位說話者、這批詞上看不到語言效應；結果當之後檢定力估計的初值 |

只有一位知道假設的說話者、20 個詞，結果只看方向與量級，計畫裡寫成「初步觀察」。
